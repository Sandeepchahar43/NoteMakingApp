# 📝 NoteMakingApp

A simple and modern Android Notes App built using **MVVM Architecture** and **Room Database**.

---

## 🚀 Features

- ✍️ Create Notes
- 🗑️ Delete Notes
- ✏️ Update Notes
- 📅 Sort Notes (Latest First)
- 💾 Offline Storage using Room Database
- 🧱 Clean MVVM Architecture

---

## 🛠️ Tech Stack

- Kotlin
- MVVM Architecture
- Room Database
- LiveData
- Search Bar
- RecyclerView and diffUtil
- DataBinding
